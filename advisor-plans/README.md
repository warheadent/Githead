## Measured baseline

Read-only measurements on `D:\Unreal` (~223,963 tracked files), taken 2026-07-12:

- `git status --porcelain=v2 -z --branch --untracked-files=all`: ~1,314 ms warm.
- The same command with `--untracked-files=no`: ~386 ms warm.
- Recursive submodule status: ~888 ms warm.
- Default-branch ahead count: ~277 ms warm.

These are diagnostic context, not CI thresholds. Automated tests must assert bounded work and correct final state, not machine-specific wall time.

## Findings considered and deferred

- Tree-mode File Status virtualization: valuable, but it does not address the switch critical path; revisit after plans 001–005 are measured.
- Diff row virtualization and batched highlighting: valuable for large selected diffs, but independent of repository switching.
- Commit-history virtualization: current history is capped at 200, so lower leverage than redundant repository scans.
- Large-scale `App.tsx` state decomposition: potentially useful but high risk; first remove backend and orchestration bottlenecks and measure remaining rerender cost.
